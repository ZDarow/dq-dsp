# Политика безопасности

## Поддерживаемые версии

| Версия | Поддержка         |
|--------|------------------|
| main   | ✅ активно        |
| 1.x    | ✅ патч-обновления |
| <1.0   | ❌ не поддерживается |

## Как сообщить о уязвимости

Если вы нашли уязвимость, **не публикуйте issue публично**.

Отправьте описание на: **security@example.com** (замените на реальный адрес).

Опишите:
- Тип уязвимости и потенциальный урон.
- Шаги для воспроизведения.
- Версию прошивки/UI.

Мы ответим в течение 72 часов и выпустим патч в течение 7 дней после подтверждения.

## Рекомендации по безопасности
- Не храните секреты в конфигурационных файлах прошивки.
- Используйте HTTPS для передачи конфигурации по сети.
- Регулярно обновляйте ESP-IDF и сторонние зависимости.
